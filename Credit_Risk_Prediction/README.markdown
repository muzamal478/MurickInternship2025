# Credit Risk & Loan Default Prediction

## Overview
Final mini-project for Murick Technologies internship. Performs EDA, feature engineering, SMOTE, trains Logistic Regression, Random Forest, XGBoost, Gradient Boosting with GridSearchCV/Stratified K-Fold, evaluates with metrics, visualizations, cost-benefit analysis, Streamlit app.

## Dataset
Loan_default.csv (5,000+ rows, features: Age, Income, LoanAmount, CreditScore, etc., target: Default).

## Files
- loan_default_prediction.ipynb
- loan_default_cleaned.csv
- recommendations.md
- requirements.txt
- visuals/ (feature_dist.png, corr_heatmap.png, confusion_matrix.png, roc_curve.png, model_comparison.png)
- app.py (Streamlit)

## Installation
1. Clone repo.
2. `pip install -r requirements.txt`
3. Run notebook: `jupyter notebook loan_default_prediction.ipynb`
4. Run app: `streamlit run app.py`
